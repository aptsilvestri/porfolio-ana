# Media

Put project images and videos here, one folder per project slug:

```
public/media/pwc-social-video/cover.jpg
public/media/pwc-social-video/loop.mp4
```

Reference them in `src/content/projects.ts` as `/media/pwc-social-video/cover.jpg`.

Guidelines
- Covers: JPG or WebP, ~2000px on the long side, under ~400 KB.
- Hover loops: MP4 (H.264), muted, 3–6 s, 720p, under ~2 MB.
- Full videos: host on Vimeo or YouTube and use an `embed` entry rather than committing large files.
